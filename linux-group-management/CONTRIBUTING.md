# Contributing

Thanks for improving this learning repository.

- Keep explanations beginner-friendly and technically accurate for RHEL 9.
- Use the pattern: concept, example, command, option explanation, expected output, practice.
- Mark commands that need `sudo`.
- Never include real passwords, password hashes, private keys, or production account data.
- Test commands in a disposable VM before proposing changes.
- Note when output or defaults can vary by system configuration.
- Prefer least-privilege examples and include verification steps.
- Keep the scope focused on groups and shared access.
