# Exercise 2 — `grep`

Run `bash lab/setup-lab.sh`, then `cd lab/sample-data`.

1. Print lines containing `ERROR` in `app.log`.
2. Search for `error` without case sensitivity.
3. Display line numbers for `ERROR` matches.
4. Count lines containing `ERROR`.
5. Print lines that do not contain `INFO`.
6. Search recursively for `ERROR` under the current directory and include line numbers.
7. Print lines containing either `ERROR` or `WARN`.
8. Print two lines of context on both sides of each `ERROR` match.
9. Find lines containing the whole word `developer` in `users.txt`.
10. Find every file containing `ERROR`.
11. Find files that do not contain `CRITICAL` among `app.log` and `error.log`.
12. Search literally for `10.0.0.5` in `access.log`.
13. Match lines that begin with `ERROR` in `error.log`.
14. Match lines ending in `READY` in `status.txt`.
15. Explain the difference between no match and an unreadable file.
